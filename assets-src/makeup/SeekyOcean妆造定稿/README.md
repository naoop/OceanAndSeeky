# Ocean & Seeky 像素造型室

首次打开显示静态双人定稿，左 Ocean、右 Seeky，两人穿 04 背带裤，Ocean 戴狼耳，Seeky 戴兔耳。静态模式没有呼吸、眨眼、跳跃或自动轮播。

## 界面与交互

- 出场可选双人、Ocean 单人或 Seeky 单人。单人居中，切换人数保留两人的个人设置。
- 着装为六套共用编号。更换着装同时更新两人的衣服，头饰独立选择。定稿中的头部搭配是原画参考。
- 头饰、表情和个人动作分别作用于当前角色。双人时用角色选择器确定编辑对象。
- 「表情」使用从动图帧提取并对齐的眼眉和嘴部图层。六套着装均可使用，两人的选择分别保存。选择静态表情时，当前角色回到站姿；播放整身动作时使用动作原画里的脸，返回定稿姿势后恢复所选表情。「动作」页签仍可选择整帧定格姿势。
- 静态模式可选择当前动作的任一姿势帧，GIF 模式按帧时长播放。切换衣服或头饰时优先保留动作，缺少对应素材时显示当前定稿姿势并保留原选择，回到兼容搭配后恢复动作。
- 双人专属动作在双人模式下共用时间轴。从单人进入要明确提示会切换双人。退出双人动作恢复个人选择。
- 第一项双人动作采用同步跳一下，静态时显示腾空姿势。牵手、拥抱待有接触动作原画后接入。
- GIF 指网页逐帧预览。本版不提供动画文件导出。

## 六套着装的动作覆盖目标

04 背带裤是首批动作样例，用于确认动作幅度、节奏和帧间对齐。最终六套着装均应支持动作。Ocean 和 Seeky 各自的个人动作保持角色归属，双人动作保持两人配套着装。

- 同步跳等只移动整个人物的动作可直接复用六套静态图。
- 做鬼脸、挥锤等现有整身逐帧动作按角色、动作、着装登记对应帧序列。衣袖、手臂或挂件随动作改变轮廓时，应按该套着装适配。涉及两人接触时还需确认遮挡顺序。
- 同一动作适配多套着装后，换装应保留动作选择并加载目标着装的帧。验收时同时检查静态选帧和 GIF 播放，两人的衣服在动作全过程保持配套。
- 当前样例的帧已画入动物耳朵。六套着装覆盖与四种头饰自由组合分别记录，避免把着装适配误计为头饰也已适配。

| 动作 | 当前覆盖 |

## 本地实现

当前可直接打开的版本采用原生 HTML、CSS 和 JavaScript。Vite + TypeScript 仍是后续工程化选项，离线 Python 流程与这项选择相互独立。入口为 `index.html`，样式在 `studio.css`，交互与动画在 `studio.js`。浏览器直接加载这三个文件，无需 Vite、TypeScript、PixiJS 或前端构建步骤。

直接打开上级目录的 index.html。HTML、CSS、JavaScript 与预处理好的 PNG 即可运行，无常驻 Python 服务。离线脚本 tools/prepare_assets.py 使用 Pillow 与 NumPy，从本目录的头部、造型和上级 gif 目录重建 studio-assets。改动预设动图后重新执行脚本。页面将着装、出场人数和预览模式与每个人的头饰、动作、帧选择分别保存于当次会话内存。

## 素材预处理

表情素材重建使用项目目录中的四张无五官头像：`Ocean01.jpg`、`seeky01.jpg` 为动物耳朵版，`Ocean02.jpg`、`seeky02.jpg` 为默认发型版。脚本对齐参考图的刘海、脸颊和下巴，取脸部区域遮住旧五官，保留着装原图的头饰、肤色及下颌线。每个动作帧单独取眼眉和嘴，按对应头型输出透明表情层。

当前定稿 PNG 是白底 RGB 图片，没有透明通道。应用开发前应从副本生成透明背景素材，原始定稿文件保持不动。

- 只删除与画布边缘连通的背景区域，避免误删白衬衫、白裤子和鞋子；
- 重点检查簪花细枝、兔耳、头发边缘、白色鞋底和浅色衣物；
- 保持原始像素尺寸，不进行有损缩放或插值；
- 所有动画帧使用固定画布、固定人物中线和固定地面线；
- 纹理打包时可以裁切透明边缘，但清单中必须保留原始锚点和偏移量，防止播放时抖动。

### Seeky 嘴唇约束

Seeky 的嘴唇不是通用像素嘴，而是固定的**心形薄唇**：有轻微丘比特弓，颜色为珊瑚粉。所有表情都应从这一结构演变。

- 微笑时保留唇峰，只抬高嘴角；
- 大笑或惊讶时可以张嘴，但上唇仍应保留心形趋势；
- 委屈或生气时可以改变弧度，不能变成厚重的圆形嘴；
- 不复用 Ocean 的嘴部素材；
- 表情审核时应单独检查嘴唇形状和颜色是否仍能识别为 Seeky。

角色视觉定稿仍参见同目录《设计要点.md》。
