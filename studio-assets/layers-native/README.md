# layers-native — 原尺寸分层（默认表情样张）

Ocean 和 Seeky 的默认造型（outfit 1），按 PSD 分层的方式拆出的头部图层。
每层都是 364×498 RGBA，和 `studio-assets/<角色>-1-x.png` 同一画布、同一锚点，没有缩放，也没有半透明像素。

## 叠放顺序（下 → 上）

| # | 文件 | 内容 |
|---|------|------|
| 0 | `headwear-ears.png` | 头饰：Ocean 为猫耳，Seeky 为兔耳。耳根和被挡住的部分已补画完整。原图里耳朵在头发、脸和身体**后面**，所以放在最底层 |
| 1 | `body.png` | 去掉整个头部的身体，保留脖子和衣领；下巴挡住的脖子部分已补画 |
| 2 | `hair-back.png` | 头发第 ① 层：后脑发团 + 脖子后、耳朵后面的碎发（下颌两侧、耳后露出来的发丝都在这一层），被脸和身体挡住的部分已补画 |
| 3 | `face.png` | 皮肤、脸部轮廓和人耳，不含五官和头发阴影；刘海下的额头和头顶补成平涂皮肤，轮廓线补完整 |
| 4 | `features.png` | 眉、眼、嘴、腮红（= 默认部件的合并版）；眉毛是**完整画好**的，被刘海盖住的眉尾、眉顶都已补全，不是断开的（Seeky 的爱心形嘴唇保持原样） |
| 5 | `bangs.png` | 头发第 ② 层（刘海）：刘海、脸两侧的鬓发、头顶，以及刘海投在额头上的阴影。取代原来的 `hair-front.png` |

头发只分两层：① `hair-back`（在五官下面）和 ② `bangs`（在五官上面）。五官夹在两层头发中间，眉毛、眼睛都画成完整的形状，被刘海自然遮住，不需要把眉毛画成断开的。

## 和原图的对应

- 6 层全部叠起来 == `<角色>-1-3.png`（戴耳朵的造型），逐像素一致，差异 0 像素。
- 去掉 `headwear-ears.png` 叠剩下 5 层 == `<角色>-1-1.png`（默认发型）。Seeky 差异 0 像素；Ocean 差 12 个像素：`Ocean-1-1.png` 在猫耳位置的头发边缘有 12 个浅色杂边像素，这些像素在 `-1-3` 里被耳朵覆盖，现在归在耳朵层。
- 每个原图像素只属于一层，取值就是原图的颜色。补画的部分只画在会被上层盖住的位置，用的都是原图调色板里的颜色，1 像素硬边，没有抗锯齿。

生成和检查脚本在制作环境里（`tools/`），不在仓库中。

## 在 PS 里修图的注意事项

- 画布保持 364×498，图层不要移动、不要缩放，保证所有层和原图对齐。
- 用 1px 铅笔工具，关闭抗锯齿，不要用柔边画笔，不要产生半透明像素。
- 修五官时把眉毛、眼睛画成完整形状，被刘海盖住的部分也要画，不要画成断开的；刘海会自然遮住它们。
- 只修被遮挡、靠补画出来的部分；在原图中可见的像素不要改，否则叠回去会和原图不一致。
- 取色只从原图里取，不要引入新颜色。
- 每层单独导出为 PNG-24 透明背景，文件名保持不变，直接覆盖。
- 叠放顺序（从下到上）：headwear-ears → body → hair-back → face → features（或 blush → eyes → brows → mouth）→ bangs。兽耳在最底层，因为原图里耳朵在头发、脸和身体后面（Seeky 的兔耳垂在肩后）。
- 兽耳取自 `<角色>-1-3.png`，其余取自 `<角色>-1-1.png`（默认造型不戴兽耳）。
- Seeky 的嘴唇是心形，这是角色设定，修改五官层时必须保留。

## 需要重点修的地方

1. face：被头发遮住的皮肤是平涂补的，单独看脸层有淡淡的接缝和几个偏亮的像素；Seeky 额头有一条偏粉的线。
2. headwear-ears：耳根贴着头发的像素带着头发原来的浅色描边或深色轮廓。Ocean 猫耳根部有一道白痕，Seeky 兔耳内侧有一道深线。
3. 眉毛被刘海盖住的部分是补画的：眉尾是逐列变细、每 3 列下降 1px 的锥形，下面带一行阴影；Seeky 的眉顶按拱形补（中间最高、两端低 1–2px），颜色取自同一条眉毛的参考列。整体能看，但形状偏规整，可以手修得更自然。
4. `brows-up`：眉毛整体抬高后大半在刘海下面，Seeky 叠起来几乎看不到上扬的眉毛（形状本身是完整的）；`brows-down` 的 Seeky 版有点方块感。
5. features 的柔和阴影（腮红、眼下、眉下）形状偏方块；`eyes-closed` 的线条比原图睫毛细；Ocean 的 `mouth-o` 偏小偏暗。
6. bangs：鬓发内侧贴脸的一圈浅粉描边是原图像素，留在 `bangs.png` 上，单独看刘海层会有粉边。
7. hair-back：耳后、颈后的碎发是从原来的前发层按“耳朵外侧、脸的轮廓以外”的规则挪过来的（Ocean 181 px，Seeky 144 px），切口处是直线，单独看后发层时这几缕发丝末端偏生硬；后发团和下巴后的脖子只是简单平涂，脖子顶端是平切的。
8. 原图本身有几处孤立的单个像素（例如 Seeky 后发左下 (137,223) 的 2 个浅色像素、衣服上的零星像素），为了和原图逐像素一致保留了它们。

## 五官部件（parts/，可自由组合）

`<角色>/parts/` 里是可以独立替换的五官部件。每个部件都是 364×498 RGBA、透明背景，和其他图层同一画布、同一锚点，直接叠在 `face.png` 上就能对准。

| 类别 | 文件 | 说明 |
|------|------|------|
| 眉毛 | `brows-default.png` / `brows-up.png` / `brows-down.png` | 默认 / 上扬（开心、得意：眉头抬高 4px，眉尾抬高 2px，整条眉毛完整，大部分会被刘海盖住）/ 皱眉（生气：眉头压低 3px，眉尾抬高 1px） |
| 眼睛 | `eyes-default.png` / `eyes-smile.png` / `eyes-closed.png` | 默认 / 笑眼（^ ^ 弧线）/ 闭眼（眨眼线，眼角有睫毛） |
| 嘴巴 | `mouth-default.png` / `mouth-open-smile.png` / `mouth-o.png` | 默认 / 张嘴笑 / 小 o 嘴（惊讶）。Seeky 的三种嘴都是心形唇 |
| 腮红 | `blush.png` | 单独一层，可以开关 |

命名规则是 `<类别>-<变体>.png`，腮红只有 `blush.png`。同一类别的部件占同一块区域，替换起来位置不会跳。

**叠放顺序（下 → 上）：** headwear-ears → body → hair-back → face → blush → eyes → brows → mouth → bangs。使用部件时不再叠 `features.png`，它只作为默认五官的合并版保留。

**默认部件 == 原图：**
- `brows-default` + `eyes-default` + `mouth-default` + `blush` 正好把 `features.png` 拆开，并集和 `features.png` 逐像素一致，没有任何像素同时属于两个部件。
- 用默认部件加腮红叠起来，和 `<角色>-1-3.png` 的差异是 0 像素（去掉兽耳后和 `-1-1.png` 的差异：Seeky 0 像素，Ocean 12 像素，原因同上）。
- 柔和阴影的归属：眼睛下方的浅粉色（虹膜下缘以下、亮度较高的像素）归 `blush`；眼睛周围其余的柔和阴影、睫毛外的浅色描边归 `eyes`；眉毛下的柔和阴影归 `brows`。

**这一版对 `face.png` / `features.png` 的改动：** 原图里眼睛、眉毛和嘴巴外面有一圈浅色或粉色的描边，原来留在 `face.png` 上，换掉五官后会露出旧五官的白边。现在把距离五官 3px 以内、颜色和肤色明显不同的像素（Ocean 271 个，Seeky 289 个）从 `face.png` 挪到了 `features.png`（也就是对应的默认部件里），`face.png` 那些位置改成平涂肤色。叠起来的结果不变，仍然和原图一致。

**新画的变体：** 在原尺寸上逐像素画，颜色只用该角色原图里有的颜色，1px 硬边，没有半透明像素。眉毛的两个变体是把默认眉毛按列整体上下移动做出来的（没有缩放，像素和原眉毛一致）。
